# Omnicanal Frontend

Cliente web de la plataforma omnicanal. Se conecta al API existente mediante `NEXT_PUBLIC_API_URL`.

## Ejecutar localmente

Requisitos: Node.js 22.13 o superior.

```bash
npm install
npm run dev
```

## Despliegue en Vercel

Configura `NEXT_PUBLIC_API_URL` con la URL pública del API backend antes del despliegue.
